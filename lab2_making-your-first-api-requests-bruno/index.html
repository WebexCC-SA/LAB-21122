    1 – Making Your First API Requests

    In this chapter, you'll dive into the exciting world of Webex APIs by making your very first requests. We'll explore different methods, starting with a quick test on the Webex Developer Portal, then moving to Bruno, and finally making a direct call using cURL.

    Upon completion of this section, you will be able to:

    1. Test Webex API requests on the Webex Developer Portal
    2. Send Webex API requests using Bruno
    3. Execute Webex API calls with cURL from the command line

    Reference:

    • Bruno
    • Webex collection in the lab repo: bruno/Webex Messaging/

    Step 1.1: Quick Test: Webex Developer Portal "Try It"

    The Webex Developer Portal is an excellent resource for documentation and quick, one-off API tests. Let's get a temporary access token and make a simple call directly from the browser.

    1. Open the Webex Developer Portal:
    2. Navigate to https://developer.webex.com/ in your browser.
    3. Get Your Temporary Access Token:
    4. On the developer portal homepage, locate the "Profile" section (usually at the top right).
    5. Ensure you are logged in with your lab credentials. If not, click "Login" and use the provided Webex email and password.
    6. Your temporary Bearer Token will be displayed. Copy this token to your clipboard. This token is valid for 12 hours.

    1. Navigate to the Webex Messaging documentation area:
    2. In the header of the portal, click on the "Documentation" drop down to expand the "Mega Nav" bar.
    3. Under the "SUITE" section, select "Webex Messaging".

    1. Retrieve Your Own User Details (GET /people/me):
    2. In the sidebar navigation, under "API Reference", expand the "All APIs" section.
    3. Then expand "People" from the left-hand menu.
    4. Scroll down to find the "Get My Own Details" GET endpoint and select it.
    5. On the right side of the page, in the "Try It" section, paste your copied Bearer Token into the "Authorization" field.
    6. Click the "Run" button.
    7. You should see a 200 OK status and a JSON response containing your Webex user details.
    8. Find Your Lab Space ID (GET /rooms):
    9. Expand "Rooms", open "List Rooms", and click "Run".
    10. Copy the id of your personal lab space.
    11. Send a Message to Your Lab Space (POST /v1/messages):
    12. Open "Create a Message", replace roomId, update the text field, and click "Run".
    13. Verify Message in Webex Client:
    14. Switch back to your Webex client and confirm the message appears in your lab space.
    15. Note: While great for quick tests, this "Try It" feature doesn't save your token or allow for complex workflows, which is why we'll use Bruno next!

    Step 1.3: Use the "Webex Messaging" Collection in Bruno

    We'll now configure authentication in Bruno and make practical API calls.

    1. Open the collection and environment:
    2. Open bruno/Webex Messaging/ in Bruno.
    3. Select the lab environment, for example Webex Prod US1.
    4. Configure collection authentication and variables:
    5. Open the collection settings or environment variables.
    6. Set webex_token to the Bearer token copied from Step 1.1.
    7. Confirm the collection auth type is Bearer Token and uses the token variable.

    Screenshot needed

    1. Make your first API call in Bruno (GET /people/me):
    2. Open People > Get My Own Details.
    3. Send the request.
    4. You should receive a 200 OK response with your user details.

    Step 1.4: Make an API Request with cURL

    Finally, let's make an API call directly from your command line using cURL. Bruno can generate the cURL command for you.

    1. Generate cURL from Bruno:
    2. Go back to the GET Get My Own Details request you successfully ran in Bruno.
    3. Open the code snippet / generate code option and select cURL.
    4. Copy the entire cURL command.

    Screenshot needed

    Add Bruno screenshot showing the Generate Code panel with the cURL snippet for GET /people/me.

    1. Open your terminal:
    2. On your lab workstation, open a terminal or PowerShell window.
    3. Execute the cURL command:
    4. Paste the copied cURL command into your terminal.
    5. If the token is still a placeholder, replace it with the Bearer token from Step 1.1.
    6. Press Enter to execute the command.
    7. Observe the output:
    8. The JSON response containing your user details will be printed directly in your terminal.

    Congratulations! You've now made Webex API requests using the Developer Portal, Bruno, and cURL.
